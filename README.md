# Forja — instaladores

Descarga la última versión desde [Releases](https://github.com/BerserkurNokk21/forja-releases/releases/latest): el fichero `Forja_*_x64-setup.exe`.

- No pide permisos de administrador.
- Windows puede mostrar SmartScreen la primera vez: «Más información» → «Ejecutar de todas formas».
- Se actualiza sola.

Este repositorio solo contiene instaladores; el código es privado.
